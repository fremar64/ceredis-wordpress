# Changelog

## 0.1.0 — Initial architecture

- Defined CEREDIS WordPress as a Git-controlled WordPress Multisite distribution.
- Pinned WordPress to 7.1.2 with PHP 8.3 Apache.
- Added immutable/read-only container strategy.
- Added initial CEREDIS Core MU-plugin.
- Added initial CEREDIS block theme.
- Added local Docker Compose environment.
- Defined separation between editorial WordPress sites and specialised applications.
