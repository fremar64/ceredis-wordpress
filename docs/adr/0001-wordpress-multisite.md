# ADR 0001 — WordPress Multisite

## Status

Accepted

## Decision

CEREDIS WordPress will use WordPress Multisite in subdomain/domain-based mode.

## Context

CEREDIS is a multidimensional programme expected to produce distinct editorial spaces for programmes such as rural agriculture financing, school-enterprise partnerships and research and development.

## Consequences

The network can add independent programme sites without creating separate WordPress installations.

Site creation remains governed: a new site is justified by a distinct editorial mission.

Specialised applications remain outside WordPress.
